# Retail Sales Analytics SQL Case Study

## Project Overview

This project focuses on analyzing retail sales data using SQL to derive meaningful business insights.

## Project Summary
This project demonstrates an end-to-end Retail Sales Analytics workflow using SQL. The analysis includes data cleaning, duplicate removal, missing value handling, date standardization, product performance evaluation, customer behavior analysis, customer segmentation, customer loyalty assessment, sales trend analysis, and month-over-month growth evaluation.

The project utilizes transactional retail datasets to generate actionable business insights that support marketing strategy, customer retention initiatives, product performance monitoring, and revenue growth analysis.

## Dataset
The project uses three datasets:

- ### customer_profiles.csv
Contains customer demographic information and customer profile details.

- ### product_inventory.csv
Contains product information, categories, inventory details, and pricing information.

- ### sales_transaction.csv
Contains customer transaction records including products purchased, quantities sold, prices, and transaction dates.

The datasets were imported into MySQL and used for data cleaning, product analysis, customer analysis, sales trend analysis, and customer segmentation.
